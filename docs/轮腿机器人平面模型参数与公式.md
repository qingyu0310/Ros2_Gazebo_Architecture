# 轮腿机器人平面模型：参数与公式

这份是 `project/tools/generate_wheel_leg_lqr.cpp` 的依据：数从展开后的 URDF 取，公式按下面的写法实现，谁都别改一处漏一处。

- 模型文件：`project/robot/models/bodys/wheel_leg_robot.xacro`
- 展开命令：`xacro project/robot/models/bodys/wheel_leg_robot.xacro`
- 下面所有数值都是**这份展开结果里的原值**，不是抄的

## 1. 链条

```text
base_link ──left_hip_joint(revolute, axis y)──▶ left_thigh_link
          ──right_hip_joint(revolute, axis y)─▶ right_thigh_link
left_thigh_link ──left_knee_cylinder_joint(fixed)──▶ left_knee_link
                ──left_knee_joint(revolute, axis y)▶ left_calf_link   (parent 是 knee_link)
left_calf_link  ──left_wheel_joint(continuous, axis y)─▶ left_wheel_link
right_* 与 left_* 完全同构，只有 y 方向的偏置取负
```

两个圆柱 link（`*_hip_link`、`*_knee_link`）挂在各自关节上，重心正好在关节轴线上，质量 0.005。

## 3. 平面共模化

- 六个关节轴全部沿 y，整台车压成 x–z 平面问题。
- 两条腿同构、共模同步运动 → 每条腿的连杆质量与惯量 ×2；左右各自的横向偏置（髋 ±0.038、轮 ±0.022）在共模下不产生俯仰和前进方向的分量，丢掉。
- 圆柱 link 的质量折进"跟它一起转"的体：`*_hip_link` 跟大腿、`*_knee_link` 跟小腿；它们的 COM 在关节轴上，惯量（3e-07 级）忽略。

折算后的四个平面体：

| # | 体 | mass /kg | Iyy /kg·m² | 本体 COM (x, z) /m |
|---|---|---|---:|---|
| 0 | 机身 = `base_link` | 1.11 | 0.0023 | (0, 0.0719922) |
| 1 | 大腿 = 2×thigh + 2×hip 圆柱 | 2×0.03 + 2×0.005 = 0.070 | 2×8.5e-06 = 1.7e-05 | (0.0214492, −0.0179981) |
| 2 | 小腿 = 2×calf + 2×knee 圆柱 | 0.070 | 1.7e-05 | (−0.0214492, −0.0179981) |
| 3 | 轮子 = 2×wheel | 0.30 | 2×0.00027 = 0.00054 | (0, 0) |

总质量 1.11 + 0.07 + 0.07 + 0.30 = **1.55 kg**，与模型一致。

平面关节原点（父体系里的 (x, z)，把中间的固定关节合并进来）：

| 关节 | 父 → 子 | 原点 d (x, z) /m | 符号 |
|---|---|---|---|
| hip | 机身 → 大腿 | (0, +0.0719922) | +1 |
| knee | 大腿 → 小腿 | (+0.0428985, −0.0359961) | +1 |
| wheel | 小腿 → 轮子 | (−0.0428985, −0.0359961) | +1 |

> `knee` 的原点是 `knee_cylinder_joint`(0.0428985, 0, −0.0359961) 与 `knee_joint`(0,0,0) 串起来的，不是 `knee_joint` 自己那个零。

## 4. 广义坐标、状态与输入

```text
广义坐标  q = [s, θ, q_h, q_k]
   s    轮心沿前进方向的位移        m
   θ    机身俯仰（绕 +y）           rad
   q_h  髋角，共模 (q_hL + q_hR)/2   rad
   q_k  膝角，共模                   rad

状态      X = [s, ṡ, θ, θ̇, q_h, q̇_h, q_k, q̇_k]^T          (8 维)
输入      U = [τ_w+, τ_h+, τ_k+]^T                          (3 维，每侧一个)
```

共模/差模与六路力矩的换算（文档 §3.3 / §3.4）：

```text
q_h+ = (q_hL + q_hR)/2      q_h− = (q_hL − q_hR)/2
τ_a+ = (τ_aL + τ_aR)/2      τ_a− = (τ_aL − τ_aR)/2        a ∈ {轮, 髋, 膝}
τ_aL = τ_a+ + τ_a−          τ_aR = τ_a+ − τ_a−
```

**注意系数**：`U` 里的一个"共模量"对应左右**各一个**执行器各出同样大小的力矩，所以对一个共模自由度做功的是 `2·τ_a+`，模型里 S 矩阵要带这个 2。

## 5. 运动学

### 5.1 轮地约束

轮心恒在 `z = r`（不脱离），纯滚动 → 轮子转角不是独立坐标：

```text
φ = s / r
```

接触力对四个广义坐标都不做功（接触点瞬时静止），所以方程里不出现 `λ`。这与文档 §4.1 的约束写法 `M q̈ + G = Sᵀτ + Jcᵀλ` 等价 —— 约束已经代进去了。

### 5.2 角度与位置

绝对角（从机身上往下累加，符号都是 +1）：

```text
ψ_大腿 = θ + q_h
ψ_小腿 = ψ_大腿 + q_k
ψ_轮子 = ψ_小腿 + φ = ψ_小腿 + s/r
```

位置从轮心往上倒推（`R(a)` 是绕 +y 转 a 的二维旋转矩阵，`d` 取上表）：

```text
O_轮心 = (s, r)
O_小腿 = O_轮心 − R(ψ_小腿) · d_wheel
O_大腿 = O_小腿 − R(ψ_大腿) · d_knee
O_机身 = O_大腿 − R(θ)      · d_hip
COM_i  = O_i + R(ψ_i) · c_i
```

### 5.3 雅可比与角速度行

```text
J_i = ∂(COM_i 的 x, z)/∂q          2×4，中心差分
w_i = ∂ψ_i/∂q                      1×4，解析：
      机身  [0, 1,        0, 0]
      大腿  [0, 1,        1, 0]
      小腿  [0, 1,        1, 1]
      轮子  [1/r, 1,      1, 1]
```

## 6. 动力学

```text
M(q) q̈ + C(q,q̇) q̇ + G(q) = S(q)ᵀ U

M(q) = Σ_i [ m_i·J_iᵀJ_i + I_i·w_iᵀw_i ]        4×4
G(q) = ∂/∂q Σ_i m_i·g·z_i(COM_i)               4×1
S    = 2 · [ 1/r   0   0 ]                      4×3
           [  0    0   0 ]
           [  0    1   0 ]
           [  0    0   1 ]
```

`S` 的由来：第 a 个输入作用在第 a 个关节的**相对转角**上，所以这一行就是 `∂(该相对角)/∂q`。髋、膝的相对角就是 `q_h`、`q_k`；轮子相对小腿的转角 `ψ_轮子 − ψ_小腿 = s/r`（约束所致），所以是 `(1/r)·e_s`。共模两侧各一个执行器，整体 ×2。

**科氏项不建**：工作点是静止的（`q̇ = 0`），而 `C(q,0) = 0`、`∂(C q̇)/∂q|_{q̇=0} = 0`，所以 A、B 里科氏项根本不出现。这不是漏了。

## 7. 工作点 X0 / U0

```text
X0 = 0        （标准腿姿：髋膝零位、机身竖直、静止）
U0 由静止方程解：G(q0) = Sᵀ·U0
     τ_h+ = G_髋(q0) / 2
     τ_k+ = G_膝(q0) / 2
     τ_w+ = G_s(q0) · r / 2
     并且必须有 G_θ(q0) = 0 —— 不为零说明几何或质量错了，静止工作点不成立
```

**标称静力对照值**（工具必须复现）：

```text
τ_h+ ≈ −0.0147 N·m      τ_k+ ≈ −0.2567 N·m       τ_w+ ≈ 0
```

## 8. 线性化与离散

```text
A = [[ 0,      I    ],        B = [[   0    ],
     [ −M⁻¹·∂G/∂q, 0 ]]            [ M⁻¹·Sᵀ ]]        A: 8×8，B: 8×3
```

- `∂G/∂q` 用中心差分，步长取 1e-4 / 1e-5 / 1e-6 三档，看 A/B 漂不漂。
- 离散（`dt = 0.001 s`，与节点的控制周期、gz 物理步长一致）：

```text
Ad = exp(A·dt)                                   零阶保持
Bd = ∫₀^dt exp(A·t)·B dt
欧拉对照：Ad = I + A·dt，Bd = B·dt
```

- `K` 用 `framework` 的 `Lqr<8,3>`，权重取 `q_pitch`（8 个）与 `r_pitch`（3 个）。

## 9. 必须过的检查（文档 §4.5）

| 检查 | 判据 |
|---|---|
| 维度 | A 8×8、B 8×3、K 3×8，与上面的顺序标签一致 |
| 有限性 | A/B/Q/R/K 里没有 NaN、Inf |
| Q | 对称半正定 |
| R | 对称正定 |
| 可控性 | `rank([B, AB, …, A⁷B])` 满 8 |
| 开环特征值 | 能看出倒立不稳定模态（有实部为正的特征值） |
| 闭环特征值 | `Ad − Bd·K` 全部落在单位圆内 |
| 步长扫描 | 差分步长变一个数量级，A/B 不剧烈漂移 |
| 左右对称 | URDF 左右两条腿的质量/惯量/几何逐项相同（工具直接比对） |
